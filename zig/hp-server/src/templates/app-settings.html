Geo-block

Optionally drop traffic from countries that are not in the allow list. Uses Cloudflare's cf-ipcountry header. Authenticated requests (you) and local requests are never blocked. Self-locking is impossible.

Comma or space separated ISO 3166-1 alpha-2 codes. Leave empty to block all (except your authenticated session).

Honeypot

When enabled, scanner-classified requests targeting common probe paths (/wp-admin, /.env, /.git/config, etc) get answered with AI-generated decoy content instead of a 403. All decoys contain only obviously fake placeholder values. Off by default. Requires the Mistral API key.

Database cache

SQLite read-side cache at ~/data/cache.db. JSONL stays the source of truth, this just makes the AI query bar fast. Auto-syncs every 5 minutes from visits.jsonl. WAL mode + synchronous=NORMAL = Android-safe.

API keys

Tokens that authorize your other apps and scripts to talk to /v1/* endpoints. Different from your operator login (which uses cookies). Each key has scopes; right now sql is the only one wired up (gives access to POST /v1/execute for arbitrary SQLite queries against DBs in ~/data/dbs/).

A new key is shown once at creation. Save it somewhere safe; we only store its hash. Revoke any time, no grace period.

Operator rules

Define your own event handlers. Each rule has a trigger (on_visit, on_login_attempt, on_blocklist_change, on_anomaly), AND-ed conditions, and a list of actions. Actions are limited to block, log, and increment. Single-user, no sandboxing nightmare. Stored in ~/.hp-server-rules.jsonl.

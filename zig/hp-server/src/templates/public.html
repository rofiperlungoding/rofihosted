The platform

Everything you'd rent. None of the rent.

Deploy from a git push

Push to main, a webhook fires, the phone clones, builds and keeps your app alive with auto-restart and rollback.

A terminal in the browser

Real shell, real history, audit-logged. I haven't opened SSH in months.

It bites back

Every scanner gets classified, rate-limited, auto-banned and annotated by AI. Probing /.env earns a 24h ban.

A database, included

Per-project SQLite, scoped API keys, a Supabase-style SQL runner. No add-on, no upsell.

It tells you when it's hurt

A public status page, uptime probes, and a Telegram ping the second someone unplugs the phone.

Deploys are atomic

Every release is a snapshot. Roll back in one click. Secrets stay in an encrypted vault per project.

A PaaS that fits in your pocket.

rofihosted is a self-hosted platform that runs an entire fullstack hosting stack on a single Android phone. Deploy from a Git URL, get a subdomain, a built-in Postgres-like database, auth, secrets, cron, and offsite backups. All written in Zig, under 18 MB.

What you get

Everything Vercel + Supabase + Railway give you, on hardware you own.

No monthly bill, no vendor lock-in, no anxiety about pricing pages updating overnight.

Git-based deploys

Paste a repo URL, pick a subdomain, click Deploy. Auto-detects React/Next/Astro/Express/Python and runs the right install + build. GitHub webhook triggers on push.

Wildcard subdomains

Every project gets <name>.rofihosted.space with TLS via Cloudflare Tunnel. No port-forwarding, no carrier-grade NAT problems, no DDNS.

Per-project SQLite

Each project gets an isolated database at ~/data/dbs/<id>.db. WAL mode, full SQL via the dashboard, accessible from your runtime through $ROFI_DB_PATH.

Auth-as-a-service

Built-in /auth/signup, /auth/login, /auth/verify on every project. JWT signed with per-project keys derived from a per-install pepper. Zero glue code.

Encrypted secrets

AES-256-GCM vault per project. Plaintext only at decrypt time. Injected as environment variables when your process starts.

Cron + supervisor

Scheduled tasks per project. Auto-restart on crash with exponential backoff. RSS quota enforcement. Survives reboots; resumes everything that was running.

Hourly offsite backups

Tarball of the entire registry + databases + secrets pushed to Cloudflare R2 every hour. Last 7 days of hourly snapshots. Full restore tested on every release.

Defense in depth

Per-IP rate limit, scanner classifier, auto-ban on probe attempts, geo-block, login brute-force tracker, AES-256-GCM at rest, HMAC sessions, no plaintext secrets.

AI assist

Mistral integration for ban annotations, daily digests, IP profiling, weekly policy review. Optional, off by default. Costs ~5 cents a month at typical volume.

Architecture

How a phone serves the world.

Your request hits Cloudflare's edge, gets piped through a tunnel into the phone, and lands on a single Zig binary that does everything.

Visitor browser, curl, bot
→
Cloudflare Edge TLS, WAF, DDoS
→
Sharp Aquos S40P
cloudflared tunnel daemon
↓
hp-server Zig binary, port 8080
SQLite per-project DB
Encrypted vault AES-256-GCM secrets
R2 backups hourly, last 7 days

No public IP needed. No port forwarding. The phone holds the outbound tunnel; Cloudflare routes traffic back through it.

Get started

Deploy in 30 seconds, not 30 minutes.

Two ways: through the dashboard, or with the rh CLI from your laptop.

Via dashboard

Click through a 4-step wizard. Auto-detect handles everything for any standard JS / Python repo.

  1. Source. Paste a Git URL or upload a ZIP.
  2. Subdomain. Pick the subdomain (live availability check).
  3. Runtime. Confirm or override the auto-detected install / build / start commands.
  4. Secrets. Drop in your environment variables. Encrypted at rest.
Open Projects

Via CLI

The rh CLI is a single Node 18+ script. Auth once, deploy from anywhere.

# Install (one-time, from the repo)
$ npm install -g ./cli

# Authenticate against your phone
$ rh login

# Deploy current directory as a static site
$ rh deploy --name my-app --runtime auto
  + zipped 142 files (3.4 MB)
  + uploaded
  + live at https://my-app.rofihosted.space
Built with

A small, deliberate stack.

No node_modules anywhere on the server. Everything is one statically-linked binary plus the tools the OS already ships.

Zig 0.14 httpz Termux (Android 11) Cloudflare Tunnel Cloudflare R2 SQLite (per-project) rclone Mistral AI vanilla HTML / CSS / JS
